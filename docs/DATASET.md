# Example dataset (SYNTHETIC)

Everything here is synthetic, generated by `data/generate.ts` with a fixed seed. Regenerate with `npm run gen:data` (output: `data/out/*.csv`, identical every run). The source of truth for the model-facing text is `lib/data/schema.ts` and `lib/data/metrics.ts`.

"Today" for every relative time phrase is **2024-12-31**. Data spans 2023-01-01 to 2024-12-31.

## Tables
- `regions` (5 rows): region_id, region_name, country_group
- `customers` (400 rows): customer_id, customer_name, email, region_id (billing), segment, signup_date
- `products` (30 rows): product_id, product_name, category, price (current), unit_cost
- `orders` (5,000 rows): order_id, customer_id, product_id, order_date, quantity, order_total (before discount), discount, status, region_id (shipping)

## Traps built in on purpose
- `orders.order_total` is before discount, not what the customer paid.
- `orders.region_id` is the shipping region; `customers.region_id` is the billing region.
- `customers.signup_date` is account creation, not first purchase.
- `products.price` is the current price; 8 products were cheaper before 2024-03-01.
- `orders.status` has four values; revenue only counts `completed`.
- Orders in the last ~10 days can be `pending`.

## Metrics
Revenue, Gross sales, Orders, AOV, Refund rate, Discount rate, Gross margin, Active customers, New customers, Repeat customers. Each has a plain definition and a hand-written reference query in `lib/data/metrics.ts`, checked in `lib/data/data.test.ts` against an independent JS computation.

Ambiguous terms (should trigger a clarifying question): "sales", "customers", "best/top" with no measure, "region", "recently".
